# 萤灯守夜 · Lantern Vigil

一个单文件 HTML 塔防游戏。墨影趁夜涌入庭院，想扑灭路尽头的心灯；你要布塔守过 30 波。

## 运行

双击 `lantern-vigil.html`，用 Chrome / Edge / Firefox / Safari 打开即可。

- 不需要安装、联网或服务器，没有任何外部资源。
- 画面用 Canvas 2D 绘制，音效和背景音乐用 Web Audio 实时合成。
- 浏览器要求先有一次点击才会出声，点"点灯开始"后声音就会响起。
- 各地图、各难度的最佳波次保存在浏览器本地存储里。

## 规则

- 敌人沿土路走向心灯，每漏过一只扣 1 点灯火，墨王扣 10 点；灯火归零即失败。
- 击破敌人获得萤露，用来建塔和升级。每守住一波有额外奖励。
- 一波清完后有 10 秒间隙，提前点"下一波"每剩 1 秒多得 3 萤露。
- 守过第 30 波即胜利，之后可以选择继续无尽模式。
- 塔只能建在空地上，土路、石头和蘑菇丛不能建。
- 每座塔可升两次（共 3 级），出售返还总投入的 70%。

## 防御塔

| 塔 | 造价 | 特点 | 对空 |
|---|---|---|---|
| 萤火弩 | 50 | 射速快的单体输出，升级还会提高射速 | 能 |
| 霜铃 | 70 | 范围脉冲，减速周围所有敌人（35% → 55%） | 能 |
| 雷藤 | 110 | 闪电连锁 3 → 5 个目标，每跳衰减 | 能 |
| 星炮 | 130 | 射程最远，范围溅射，带预判落点 | 不能 |
| 光棱 | 160 | 持续光束，照同一目标越久伤害越高，无视护甲 | 能 |

点击已建的塔可以切换目标优先级：最前 / 最强 / 最近。

## 技能

- **流星（Q）**：点击地图任意位置，范围重创，可打飞行。冷却 30 秒。
- **凝霜（W）**：冻结全场敌人 3.5 秒。冷却 45 秒。

## 地图与难度

- **蜿蜒小径**：一条长路，拐弯多，适合上手。
- **双岔河口**：两路来敌在中段汇合，前期要兼顾两边。
- 难度 **闲庭 / 守夜 / 长夜**：敌人血量 ×0.8 / ×1 / ×1.3，初始萤露和灯火依次减少。

## 小提示

- 拐角处的格子能覆盖更长的路，优先放那里。
- 霜铃放在输出塔旁边，减速等于让所有塔多打几轮。
- 夜蛾走直线，不经过弯道；在起点到心灯的连线附近留几座对空塔。
- 墨王波把光棱的目标设成"最强"，持续照射收益最高。

## 测试情况

逻辑部分在无界面环境下用自动脚本跑过两张地图、三档难度的完整对局，没有报错。平衡性也是据此调的：一个不讲策略的脚本在"闲庭"能通关，在"守夜"会倒在 27–29 波附近。画面和音效没有经过真人在浏览器里试玩，如果遇到显示或手感问题，告诉我具体现象即可修改。
